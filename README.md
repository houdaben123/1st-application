# 📝 To-Do App

تطبيق إدارة المهام البسيط والسهل الاستخدام!

## ✨ المميزات

- ✅ إضافة مهام جديدة
- ✅ حذف المهام المنتهية
- ✅ حفظ البيانات تلقائياً (localStorage)
- ✅ تصميم أنيق وسهل الاستخدام

## 🎨 التصميم

- ألوان أزرق وأبيض
- واجهة بسيطة وجميلة
- متجاوب مع الهاتف ✓

## 🚀 كيفية التشغيل

1. اكتشفي المشروع:
```bash
git clone https://github.com/houdaben123/1st-application.git
cd 1st-application
```

2. افتحي `index.html` في المتصفح

3. ابدأي بإضافة مهامك! 📌

## 💻 التقنيات المستخدمة

- **HTML5** - الهيكل الأساسي
- **CSS3** - التصميم الجميل
- **JavaScript** - الوظائف التفاعلية
- **localStorage** - حفظ البيانات
